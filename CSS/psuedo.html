Registration Form


  1. HTML stands for HyperText Markup Language.
  2. CSS stands for Cascading Style Sheets.
  3. JavaScript is a programming language used to create interactive effects within web browsers.

This is a registration form created using HTML and styled with CSS.
The form includes fields for the user's name, email, and password, along with submit and reset buttons.
The CSS styles the form elements to enhance their appearance and usability.
The heading "Welcome to day-6" is styled with a pseudo-element to add the word "Class" after it, and the second heading has its first letter styled differently for emphasis.



The ordered list is styled to remove the default numbering and replace it with custom markers (arrows) for each list item.
The input fields change their background color and border when focused, providing visual feedback to the user.
Additionally, the link changes its appearance when hovered over, enhancing the user experience. Overall, this code demonstrates the use of various CSS pseudo-classes and pseudo-elements to create a visually appealing and interactive web page.
